# Product — app.civiumcre.com (composition)

The product's source (`ccrouch-cyber/civium`, `frontend/src/*.jsx`, `index.css`) is private and was not available. This kit is therefore **not** a recreation of real screens: it composes only the system's components and the copy that appears in the design-system previews (the drop card, the deal name, the lanes, the receipt's numbers) following the brand book's page rules (paper ground, one serif h-page title, cards on line, gutter 24, shell 1180).

Screens (click-through in `index.html`): SignIn → Desk (drop a deal, filter pills, the deals) → Deal (Rent Roll Analyzer lane: metric strip with receipts, unit lines). Other lanes are left blank on purpose.

Files: `Shell.jsx` (header with brand mark, sign out), `SignIn.jsx`, `Desk.jsx`, `Deal.jsx`.
Replace with real layouts once the product frontend is shared.
